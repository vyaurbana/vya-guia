# VYA GUÍA

Guía de programación (EPG) para VYA PLAYER.

- `hacer_guia.py` descarga la guía española gratuita de EPG_dobleM y deja solo lo necesario en `guia.json`.
- GitHub lo ejecuta solo cada 4 horas (`.github/workflows/guia.yml`).
- Las teles leen: https://raw.githubusercontent.com/vyaurbana/vya-guia/main/guia.json
